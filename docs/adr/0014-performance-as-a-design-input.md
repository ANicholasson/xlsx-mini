# Performance is a design input with measured, ratcheting budgets

The hot path (cell normalisation, escaping, interning, style lookup, part assembly, CRC, compression) follows fixed rules: one pass over rows, chunked string building with one encode per part, precomputed column letters, a CRC table built once, an escape fast path that scans char codes and copies only when needed, no regular expressions or per-cell closures or objects, and the async boundary only at compression. Benchmarks live in the repository and run on every pull request through CodSpeed, whose CPU simulation gives stable deltas where shared runners do not. Budgets are set from the first measured baseline and only ratchet down.
