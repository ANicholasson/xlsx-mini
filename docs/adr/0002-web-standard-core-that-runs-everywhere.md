# A web-standard core that runs on every JavaScript runtime

The core uses only web-standard APIs (`TextEncoder`, `Uint8Array`, `CompressionStream`): no `node:` modules, no DOM globals, no `Buffer`. Runtime-specific behaviour lives in subpath entries such as `xlsx-mini/browser`, following the pattern of libraries that ship adapters as subpaths. Supported engines are Node `^20.12 || >=22`, evergreen browsers and edge runtimes, and "works everywhere" is a tested property: the runtime matrix in CI produces a workbook in Node (ESM and CommonJS), Cloudflare workerd, Bun, Deno and the Vercel edge runtime. Lint rules forbid the restricted globals and imports in the core so the property cannot erode silently.

Every host of the matrix writes the same scenario workbook through the built package and reports back. Node, Bun and Deno load both entries by name, so the exports map is exercised rather than linted; workerd runs inside Miniflare and the Vercel edge runtime inside its VM package, both fed a rolldown bundle of `dist/`, the way a deploy tool would ship it. STORE output must be byte-identical on every host and to the source run in the test's own Node; the default output must carry the same parts. The zip method is pinned per host, so a host gaining or losing raw deflate fails a test instead of changing silently. The edge VM package has no `CompressionStream`, which makes it the standing proof of the STORE fallback.
