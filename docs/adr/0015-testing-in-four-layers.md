# Testing in four layers, with real readers as the acceptance

Unit tests cover the mechanics (escaping, column letters, serials, CRC, zip layout, index consistency), with property-based tests where inputs are open-ended. Golden fixtures are compared byte for byte for STORE output and part by part as decompressed XML for DEFLATE output, read back by a small in-repo unzip helper on `node:zlib` so no zip library enters even the dev dependencies. In CI, LibreOffice converts every fixture to CSV headlessly and the values are compared, an independent parser on every push. Before a release the fixtures are opened by hand in Excel, Numbers, Google Sheets and LibreOffice and the result is recorded in the compatibility log. Green checks gate; opening clean in real applications is what accepts.
