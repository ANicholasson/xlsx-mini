# Vite+ as the single development toolchain, TypeScript 7 for emit

Formatting, linting with type-aware rules, and tests come from one dev dependency, Vite+ (`vp`), which bundles oxfmt, oxlint and vitest; `tsc` from TypeScript 7 emits the package and runs the typecheck. knip finds dead exports and dependencies, dependency-cruiser enforces boundaries, fast-check drives property tests, changesets manages releases. A pre-commit hook through Vite+'s dispatcher formats and lints staged files and typechecks; CI is the real gate. Biome is the fallback if Vite+ proves too young.

Test-only additions for the runtime matrix and the manifest: Miniflare and `@edge-runtime/vm` host the matrix, rolldown bundles `dist/` for them, publint and are-the-types-wrong check the package. Bun and Deno are ordinary devDependencies; pnpm 12 resolves those two names to official runtime builds (`runtime:` entries in the lockfile, no install scripts), so `pnpm install` is the whole setup. pnpm's `devEngines.runtime` form was tried and rejected: npm reads it as a demand to develop with Deno or Bun and refuses to run anything in the project. Install scripts are opt-in through `allowBuilds` in `pnpm-workspace.yaml`; only workerd runs one.
