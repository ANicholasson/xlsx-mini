# xlsx-mini

A zero-dependency TypeScript library that writes `.xlsx` files and runs everywhere JavaScript runs: Node, Bun, Deno, Cloudflare Workers, browsers.

This is a placeholder release line. The first documented release is 0.1.0; until then, the [repository](https://github.com/ANicholasson/xlsx-mini) has the design decisions under `docs/adr/`, the compatibility log, and the benchmarks.
